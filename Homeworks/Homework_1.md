## Створення класу "Банківський рахунок"

Мовою програмування C# створити клас `BankAccount` (Банківський рахунок), який моделює управління балансом рахунку з базовими фінансовими операціями та захистом від несанкціонованого зняття коштів.

### Поля класу BankAccount

| Поле | Тип | Опис |
| :---- | :---- | :---- |
| `AccountNumber` | ![string-badge] | Номер рахунку |
| `OwnerName` | ![string-badge] | Власник рахунку |
| `Balance` | ![decimal-badge] | Поточний баланс |

### Методи класу BankAccount

| Метод | Параметри | Опис |
| :---- | :---- | :---- |
| `Deposit` | ![decimal-badge] amount | Поповнення рахунку |
| `Withdraw` | ![decimal-badge] amount | Зняття коштів із перевіркою на достатність суми |

Перевірити **успішне поповнення**, **коректне зняття коштів** за наявності потрібної суми, а також **відхилення операції** при спробі зняти більше, ніж є на балансі.
